# Client Logos

This directory should contain the logo images for clients you've worked with.

## Expected Files:
- `qpharma-logo.png` - QPharma Inc logo
- `tapestry-logo.png` - Tapestry logo  
- `regeneron-logo.png` - Regeneron logo
- `digi-logo.png` - Digi Malaysia logo
- `stc-logo.png` - STC (Saudi Telecom) logo

## Logo Requirements:
- Format: PNG or SVG preferred
- Size: Recommended 200x100px or similar aspect ratio
- Background: Transparent or white background
- Quality: High resolution for crisp display

## Usage:
These logos will be displayed in the "Clients I've Worked With" section on the home page.
