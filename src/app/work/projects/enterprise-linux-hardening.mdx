## Overview

This Systems Administration project focused on reducing operational risk by strengthening the security baseline for Linux servers and formalizing patch compliance across environments.

---

## Key Highlights

- Hardened server baselines for SSH, firewall, file permissions, logging, and service isolation.
- Automated patching and compliance checks using configuration management and scripting workflows.
- Reduced drift across environments using repeatable build and configuration standards.
- Created exception handling and evidence-based remediation for compliance gaps.
- Improved uptime by standardizing maintenance windows and health checks.


---

## Outcome

The environment became more secure, easier to govern, and far more predictable during audits and change windows.
