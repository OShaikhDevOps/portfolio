## Overview

This ML Engineering project focused on applying computer vision to industrial quality control. The solution automated visual inspection workflows and increased consistency in detecting anomalies across production batches.

---

## Key Highlights

- Collected and labeled image datasets for defect detection and quality classification.
- Developed model training pipelines using OpenCV and Python-based preprocessing.
- Created deployment patterns for real-time inference and batch analysis on scalable infrastructure.
- Added model quality monitoring and retraining triggers based on drift and performance shifts.
- Integrated results into operational dashboards and alert workflows for factory teams.


---

## Outcome

The organization improved inspection consistency while reducing manual review time and catching defects earlier in the production lifecycle.
