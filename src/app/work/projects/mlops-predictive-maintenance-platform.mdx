## Overview

This project focused on building a production-grade machine learning lifecycle for predictive maintenance using AWS and Kubernetes. The platform handled data preparation, training orchestration, model validation, feature tracking, and deployment through an automated CI/CD workflow.

---

## Key Highlights

- Designed data pipelines for ingestion, preprocessing, and feature engineering from sensor telemetry.
- Implemented experiment tracking and model registry using MLflow and artifact versioning.
- Automated retraining triggers based on drift thresholds and performance degradation.
- Deployed inference services on Kubernetes with autoscaling, canary releases, and rollback safeguards.
- Built monitoring dashboards for latency, model drift, and operational health.


---

## Outcome

The team reduced model deployment time from weeks to days while improving trust, observability, and release confidence in production ML workflows.
