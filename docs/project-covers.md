# Project covers

Generated using the built-in image_gen tool. Conceptual illustrations, not architecture diagrams or product screenshots.

Each asset lives at `public/images/projects/<slug>/cover.webp` and is referenced in its project MDX frontmatter. Original SVGs are retained. WebP quality 84, maximum width 1600 px, aspect ratio preserved.

For future covers: use the shared prompt plus a project-specific subject, generate one image per project, inspect the result, convert to WebP, and update the MDX images entry. Keep subjects centered for responsive cropping. Use new filenames for revisions.
